# 创意创作视频人物替换

创意创作右侧提供独立的“视频人物替换”入口，面向单人视频。人物图片选传，可从历史图片选择；没有图片时按文字描述生成。声音提供三种常用方式：保留原声与台词；沿用原视频音色说新台词；换新音色说新台词。另提供静音选项。后两种方式使用独立的新台词输入框。沿用原音色需要原视频有清晰人声；换新音色可描述目标声音，不填时按人物要求匹配新声音，也支持原视频无音轨的情况。

“人物替换要求”旁提供“保存要求”和“要求历史”。提交成功建立任务后自动保存要求，也可不提交任务直接保存；历史按最新使用时间排序、去重，最多保留100条，支持搜索、查看全文及一键填入继续修改。手动保存的要求存于当前浏览器，历史列表同时收录服务端本设备最近任务的要求；只回填人物要求，不改变声音、台词、模型或上传素材。

原视频的“历史视频”和人物参考的“历史图片”与左侧共用 `UploadHistoryPreview` 大预览窗口。点击缩略图只读取原文件并预览，不直接改动本次素材；视频提供播放控件、静音循环预览及实际时长，图片使用原图查看大图。点击“选用此视频/图片”才回填，点击“继续浏览”、关闭按钮或 Escape 返回列表。预览关闭后释放临时文件地址；列表关闭或组件卸载后忽略尚未完成的历史读取。空文件、文件已删除、浏览器无法解码及不符合本模块格式或大小要求时提供提示。预览不刷新素材使用时间；明确选用后才更新记录。要求历史被选用或待确认提交找回成功后，也会保存到本地要求历史并更新最近使用时间。

两侧历史视频的列表缩略图共用 `HistoryVideoThumbnail`：固定预览区域，按原比例完整显示缓存帧，横屏和竖屏均不裁切、不拉伸，也不让图片原始尺寸撑开容器。竖屏留左右空边。人物替换列表的预览图标只在悬停或键盘聚焦时显示，避免持续遮挡人物和商品。

## 配置与运行

沿用现有服务端配置：

- `MEDIAKIT_API_KEY`：AI MediaKit 人脸打码访问凭证。
- `SEEDANCE_API_KEY`：Seedance 视频生成访问凭证。
- `PUBLIC_BASE_URL`：火山可以访问的应用公网地址。
- 服务器需要 `ffmpeg` 和 `ffprobe`，用于读取视频及处理原声。

无需新增依赖。重新构建前端并重启后端即可载入代码。

## 视频参数

原视频使用50MB以内的MP4或MOV，分辨率不超过4K。

- Seedance 2.0：4至15秒，480P或720P。
- Seedance 2.5：4至30秒，当前界面使用720P。
- 人物图片：选传，最多1张，10MB以内的JPG、PNG或WebP。

生成接口使用参考视频加可选人物图片，不走左侧反推，也不注入挂画、贴画或摆台的专用规则。Seedance 2.5 使用 `omni_reference_task_type: edit`、`ratio: adaptive` 和 `duration: -1`，让模型跟随原片时长和比例；2.0 按支持的整数秒请求时长。新的有声任务开启模型声音能力，直接保留模型返回的音视频，不覆盖音轨或重新调整时间。升级前已创建的任务保留原处理规则。

## 输入打码与成片面部

打码视频只作为输入预处理，脸部打码不属于要复刻的人物外貌或原片效果。人物替换提示词在开头明确素材职责，在保留范围中将脸部打码列为必须清除的内容，并在结尾重申成片要展示自然的新人物面部。人物图选传时由参考图决定新脸；无参考图时按人物要求生成新脸，不识别或还原原人物身份。

“其余不变”不包括临时打码区域；移动、转头、侧脸和说话时也不能继承该区域的遮罩。同时保留真实的头发、手部及道具遮挡，不要求人物强行转正、不新增面部特写、不改变镜头。此规则覆盖两种模型和所有声音模式，不增加提示词过滤或自动付费重试。对后续提交和手动重试生效，已经提交给模型的任务不会因提示词更新而自动重新提交。

这是提示词层面的改进，不能代替真实视频的生成效果验证，也不承诺模型绝不生成错误遮挡。

## 后台流程与恢复

原视频保存到任务目录；不符合MediaKit帧率范围时先转成30fps。之后调用MediaKit人脸打码异步接口，轮询完成后立即保存打码视频，避免依赖24小时临时地址。仅打码视频送入Seedance；如果打码工具遗漏音轨，在提交模型前把原音轨补入打码视频，保证模型能参考原声。默认模式要求模型保留原声、原台词并同步新人物口型；改台词模式明确以原人声为音色参考，逐字说新台词并重新同步口型，不沿用旧台词口型。仅在默认模式的模型输出完全没有音轨且时长接近原片时，才用原音轨补回并提示检查口型。新台词模式绝不用旧音轨覆盖；模型没有返回人声时保留画面供查看，用户重试会重新生成声音和画面。

任务写入现有SQLite数据库的 `person_replacement_jobs` 表，文件位于 `RUNTIME_STATE_DIR/person-replacement`。进度包含上传、格式准备、打码、保存打码结果、人物替换、声音处理和完成。页面读取当前设备最近50条记录，刷新或后端重启后继续处理已持有任务编号的任务。

## 多设备独立使用

复用浏览器本地的稳定设备标识 `kelong-device-id`，所有任务创建、列表、查询、重试、找回及保存接口均通过 `X-Device-Id` 传递。服务端在独立的 `device_id` 列记录归属，先筛选设备再取最近50条；其他设备的任务不会进入本设备的记录、要求历史或表单锁定状态。后台工作队列继续处理所有设备的任务，每轮最多同时推进两个处理步骤，不按设备互斥。主动保存到素材库的成片仍沿用素材库的共享规则。

设备按浏览器本地数据区分；清空浏览器数据或更换浏览器会使用新的设备标识。升级前没有归属的记录保留在服务端，但不再向所有设备展示，也不推测归属。浏览器仍保存原随机提交编号的待确认任务，可通过原有“查询上次提交结果”认领并恢复，认领不重新打码或生成。上游取素材和任务通知仍使用各任务独立的随机令牌，不要求设备请求头。

同一提交编号只建立一个任务。查询异常只继续查询，不重复提交。已确认失败的任务支持用户手动重试，并复用已完成的打码。

Seedance提交等待时间为180秒（打码提交仍为60秒）。任务在提交前持久化独立的随机通知令牌，并通过官方 `callback_url` 注册状态通知。提交超时、连接中断、5xx或重启时未拿到任务编号，进入“提交待确认”，保留打码视频，等待通知；不把网络超时等同于模型生成失败，不自动重发付费请求。

回调只用于找回任务编号，状态和成片地址仍通过服务端凭证查询官方任务接口获取。无效通知令牌、模型不符、冲突编号会被拒绝；重复或延迟通知不会把已完成的任务退回处理中。通知先于提交回复到达或提交回复最终超时时，也保留已找回的编号。

页面提供“找回已有任务”入口。用户可从火山后台复制对应这条视频的任务编号，后台核对模型、分辨率及可用的创建时间后关联，继续查询和保存，不重新打码、不重新生成。该入口也兼容升级前已记录为“处理未完成”的提交结果未确认任务；旧任务没有注册通知，不能承诺它会自动收到通知。

成片可下载或保存到视频素材库；优先保存模型原生输出，仅静音和缺音轨备用处理会另行处理音轨。人物替换与常规生成、元素替换共用同一个保存弹窗：自动匹配文件夹、记住上次实际保存的位置，允许手动更换并确认。文件名统一为上海时间的“月日 时分.mp4”，入库备注使用相同的模型和来源格式。服务端共用无损入库函数，保存最终的 `result.mp4`，不会改存原视频或绕过声音处理去下载模型原片；核对文件大小、按内容去重、生成预览，并检测480P自动进入1080P增强。重复入库返回素材实际所在文件夹，不重复插入或移动素材。保存成功的文件夹和素材编号会写回本设备任务，刷新后显示“已保存至…”；主动入库的视频仍按素材库规则共享。

## 接口

- `POST /api/person-replacement/tasks`：multipart上传，字段为 `creationRequestId`、`prompt`、`model`、`resolution`、`audioMode`、`dialogue`、`voiceDescription` 和 `files`。`audioMode` 使用 `preserve`、`rewrite`、`new-voice` 或 `silent`，兼容升级前的 `generate`；`rewrite` 和 `new-voice` 时 `dialogue` 必填，`new-voice` 可选填 `voiceDescription`（最多500字）。
- `GET /api/person-replacement/tasks`：当前设备最近50条任务。
- `GET /api/person-replacement/tasks/by-request/:requestId`：网络中断后的提交查询。
- `GET /api/person-replacement/tasks/:id`：任务状态。
- `POST /api/person-replacement/tasks/:id/retry`：从可恢复阶段继续。
- `POST /api/person-replacement/tasks/:id/recover`：传入火山 `taskId`，仅查询已有任务并关联恢复。
- `POST /api/person-replacement/callback/:id/:token`：供火山发送任务状态通知，随机令牌认证，在应用登录检查之前接收。
- `POST /api/person-replacement/tasks/:id/save`：将成片保存到指定素材库文件夹。
- `GET/HEAD /api/person-replacement/media/:id/:token/:file`：带随机令牌的媒体读取，支持Range；仅允许固定媒体文件名。该入口在登录检查之前供上游取素材，其余任务接口沿用应用登录检查。
