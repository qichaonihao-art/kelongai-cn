# PVC背胶贴画创意素材

入口：创意创作 → 装饰画创意素材 → PVC背胶贴画。原挂画／卷轴流程保留。

## 产品档案

- 默认宽180厘米、高60厘米，横款3:1；宽高可在分析前修改。
- PVC柔性薄片、白色画背、可揭离背膜、印刷假框。
- 主图负责文字、图案、颜色，结构由产品类型固定；不猜测无法辨认的小字。
- 不带木条、挂绳、挂钩，不使用小胶带定位，不套用挂画尺寸补偿。
- 白色背面属于画身，背膜才是另一个被揭离的物体；贴好后不二次展开。

## 40个方向

| 组 | 方向 | 内容 |
|---|---|---|
| 第一组 | 1–10 | 画旁讲解、走近欣赏、长辈讲字、双人品评、整理软装、起身看画、茶席介绍、朋友来访、手机取景、轻触成品 |
| 第二组 | 11–20 | 斟茶、阅读、落笔、会客递杯、餐厅花瓶、开帘、茶具整理、灯下阅读、绿植、无人茶室 |
| 第三组 | 21–30 | 左右横移揭示、推进文字、拉远全貌、正反文字巡游、假框细节、贴墙薄边、前景揭示、低位升起 |
| 第四组 | 31–40 | 双人展示、搬运比位、桌面揭膜起角、双人揭膜、左右局部贴合、卷材滚动、未贴区域压实、最后压边、双人完成后让出 |

前30个方向已贴好，后10个只演示各自明确的形态/安装片段，不要求短视频完成整幅施工。主要场景为茶室、客厅、书房，不默认床头。保留推进特写，镜头结尾不能越过产品。

## 流程隔离与兼容

- `profile.productType` 贯穿分析、创意、完整提示词和批量快照；旧档案缺失该字段时按挂画处理。
- 方向编号在类型内独立：贴画的1、8、29、30不会触发挂画同号方向的展开、木条或特写规则。
- 手动提交携带产品类型；贴画文案头部保留尺寸和方向，复制/重试时也可恢复所属规则。
- 六个现有模型共用贴画规则；千问仍附加运镜规则，但不附加卷轴拓扑/挂钩规则。
- 切换类型或改尺寸后重新分析，清理方案与待用提示词；已启动的后台批量任务继续使用启动时快照。
- 历史按类型标注和恢复，同图的两种创意历史不互相覆盖。使用方向记录按类型隔离，旧挂画记录保持有效。
- 素材库文件夹匹配继续按图片/画名复用（同一内容可以存同一目录），下载和自动增强逻辑不变。
