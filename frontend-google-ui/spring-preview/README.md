# 春节配色本地预览

在 `frontend-google-ui` 目录运行：

```sh
./node_modules/.bin/vite --config spring-preview/vite.config.ts
```

打开 [春节配色预览](http://127.0.0.1:5176/spring-preview/)，使用演示密码 `2027` 登录。顶部可切换「春节配色」和「当前配色」，切换时保留当前页面及页面状态。

预览使用现有应用的页面和导航。春节颜色只作用于登录页和工作台首页。各模块可打开查看原有界面，业务服务使用本地演示数据或离线提示。预览服务仅在本机运行。

确认后再将配色接入正式站的独立主题开关，关闭开关即可恢复当前配色。
