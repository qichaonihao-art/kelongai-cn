# 全站 UI 本地预览

本目录是独立的全站界面提案，未接入正式入口，不修改 src/App.tsx、正式主页或业务模块源文件。

在 frontend-google-ui 目录启动：

```sh
./node_modules/.bin/vite --config home-preview/vite.config.ts
```

访问：http://127.0.0.1:5175/home-preview/

## 覆盖范围

九个站内一级模块：创意创作、图片生成、声音克隆、视频解析、顶级模型、创意文库、视频素材库、店铺总览、团队轨迹。

同时覆盖视频创作、镜头截取、文案创作子页，以及原组件中的反推、元素替换、图片生视频、AI素材生成、视频编辑、人物替换、历史面板、参数弹窗和记录编辑界面。视频解析里的外部网站链接仍访问原站，不在本提案范围内。

顶部「新版界面 / 原版对比」在当前模块切换视觉版本；模块切换和原版对比会按原应用方式重新挂载业务组件。全局工具搜索不会卸载当前编辑器，关闭搜索后保留未提交内容。

## 实现边界

HomePage.tsx 是共用导航和工作区外壳，modules.css 为内页提供作用域明确的颜色、控件、表单、上传、布局和弹窗规范。状态警告/错误颜色与店铺图谱节点分类颜色保留。没有修改图片/视频内容、提示词、产品参数、模型或生成逻辑。

ModuleQuickNav.tsx 仅在新版共用外壳内隐藏重复的横向导航。presentationAdapters.ts 只在此 Vite 配置下为图片/模型页适配历史侧栏的响应式展开状态，给图片历史按钮补充可访问名称；正式源文件不变。

## 离线限制

预览服务只监听 127.0.0.1。少数列表 GET 返回本地空列表和默认空文件夹，便于检查实际组件的空状态；其他 API（包括所有写入和生成请求）一律返回 503。不连接线上素材、共享记录或付费生成。

顶部已经标注本地空数据。配置警告、不可用状态属于离线预览限制。真实生成、后台读写、带数据的长列表和已有任务恢复尚未在此预览里进行联调。

本机最近访问和团队标语采用 kelong:home-design-preview: 前缀；模块仍使用其原有本机历史机制，请勿将对比/导航过程中的编辑当作线上业务操作。
